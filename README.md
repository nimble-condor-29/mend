mend applies an edit that an AI model wrote to a tree of text files. It reads all four formats models write — unified diffs (with wrong line numbers), SEARCH/REPLACE blocks, V4A patches and text-editor tool calls as JSON — matches old lines at three exactness tiers, and changes every file or nothing.

## Run it

```sh
node main.ts [--format=NAME] [--check] [--strict] [PATCH]
```
